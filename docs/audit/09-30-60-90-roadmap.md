# 30 / 60 / 90-day roadmap

The plan assumes one product/engineering owner, one design/frontend owner, one SEO/content lead, native English editorial support, and access to operations/account teams for proof. Sequence matters: reliability and index integrity precede redesign/content scale.

## First 30 days — stabilize and clarify

### Week 1: stop critical loss

- fix DB/session pooling and reproduce a zero-error concurrency baseline;
- make CI fail on prerender/content-query errors;
- remove/null-proof broken English cards and unpublish test routes;
- choose one canonical host and update every generated URL source;
- add route/status smoke tests and production alerting;
- collapse/fix mobile floating CTAs and urgent overflow.

Exit criteria:

- agreed concurrency test has 0 unexpected non-2xx;
- build has no DB errors and fails if one occurs;
- no public internal link resolves to null/test/404;
- all declared canonicals are final-host 200s;
- no clipping on primary flows at 320/375/390/430/768.

### Week 2: repair crawl and locale integrity

- rebuild sitemap from validated published records;
- remove noindex/test/dead routes from sitemap;
- add English detail routes with true `lastmod`;
- enforce reciprocal hreflang only for complete locale pairs;
- replace Turkish fallback behavior with draft/noindex rules;
- fix English legal/footer paths or temporarily suppress unavailable alternates;
- correct misspelled English project URL with tested 301 if changed.

Exit criteria:

- sitemap contains all and only canonical 200/indexable pages;
- every hreflang target returns 200, self-canonicalizes, and reciprocates;
- no indexable English page contains Turkish fallback metadata/body.

### Week 3: metadata, schema, tracking and accessibility

- repair top-priority titles/descriptions/H1s;
- remove global SoftwareApplication/rating, fix logo/OG fallback, and publish page-accurate schema;
- consolidate GTM/direct gtag and verify conversion events;
- fix footer contrast, reduced-motion and primary keyboard/focus defects;
- publish a concise legal-approved data/image processing summary;
- document claim sources for 1K+/100+/30-day/99% statements.

Exit criteria:

- top 20 commercial/case pages pass metadata/schema/share preview QA;
- analytics has no duplicate pageview/conversion firing;
- unsupported claims are removed or scoped/evidenced;
- core templates pass keyboard and contrast checks.

### Week 4: positioning and conversion baseline

- approve primary/secondary/SEO/sales positioning;
- implement new homepage hero copy and primary CTA without full redesign;
- add strongest existing showreel/still and selected client proof near top;
- create one event-brief form with source/service/project capture;
- add contextual service/project links on top pages;
- establish reporting baseline: crawl health, indexation, organic landing conversions, lead quality.

Exit criteria:

- five-second stakeholder/user check correctly identifies company, audience, difference and next step;
- event brief feeds the real sales workflow;
- baseline KPI dashboard is documented.

## Days 31–60 — build proof-led core pages

### Homepage and system

- restructure homepage around positioning → showreel → clients → cases → capabilities → delivery → outcomes → international/CTA;
- implement the lightweight design tokens and three-font system;
- optimize critical media and lazy-load nonessential interactive UI;
- verify mobile and accessibility in the component library.

### Services

- consolidate taxonomy into five capability groups;
- rebuild AI Event Activations and AI Photo Booth first;
- rebuild Branded Photo/Video, Games and Installations hubs based on evidence;
- consolidate/noindex weak formats and apply relevance-preserving redirects;
- add guest journey, technical/production, data, case and brief modules.

### Cases

- collect approved data/assets for Adidas, Pegasus, BSH, DeFacto/Afra and Tavuk Dünyası (substitute where rights/evidence are unavailable);
- implement reusable case template;
- create project-specific OG assets;
- add service/solution relationships and contextual CTAs.

### About/trust

- add team, process, prototyping/production, operating model and verified markets;
- publish native English About, privacy/terms, and data/safety material;
- accurately credit clients, agencies and production partners.

60-day exit criteria:

- home, service hub, top three capability pages and five flagship cases are live in native TR/EN;
- no orphaned commercial hub;
- top landing pages meet performance/accessibility budgets;
- sales can answer enterprise reliability/data questions from the site.

## Days 61–90 — grow authority and test

### Solutions and search authority

- publish up to four evidence-led solution pages: trade shows/conferences, product launches, retail/in-store, corporate events;
- publish the first English commercial-support cluster: AI Photo planning, AI activation guide, brand-safe/data guide and one technical case;
- update/consolidate Turkish posts and add service/case links;
- decide whether software-sector pages become a separate real offering or are consolidated.

### International growth

- define verified delivery markets, crew/partner model and proposal language;
- build market pages only where operations, cases and demand justify them;
- run English SERP/GSC review after pages are indexed;
- begin agency-partner outreach and authority building to relevant event/experiential publications, using actual cases rather than generic guest posts.

### Optimization

- review qualified brief rate by source page and locale;
- test one homepage promise/CTA hypothesis;
- test case-card result framing;
- refine brief fields based on sales response quality;
- monitor CWV field data once sufficient traffic is available;
- run quarterly broken-link, hreflang, schema, screenshot, performance and claim audits.

90-day exit criteria:

- reliable indexable architecture and measured organic conversion baseline;
- strong native English commercial footprint around the highest-relevance clusters;
- at least five procurement-grade cases;
- one completed CRO experiment with qualified-lead outcome;
- no unowned thin/programmatic page family.

## Weekly operating cadence

| Cadence | Participants | Output |
|---|---|---|
| Monday release-health | engineering, SEO | status errors, DB saturation, build/smoke test, index anomalies |
| Biweekly content gate | content, SEO, ops, native editor | approve intent, proof, claims, translation, links and media |
| Biweekly sales feedback | sales/account, CRO | lead quality, missing buyer questions, CTA/form friction |
| Monthly scorecard | leadership, marketing, product | qualified briefs, organic contribution, top landing pages, delivery risks |

## KPI framework

### Reliability and technical

- unexpected 5xx rate by route/locale
- build/smoke-test pass rate
- valid indexable URLs and hreflang error count
- crawl-discovered broken internal links
- mobile field CWV when available

### Acquisition

- non-brand organic clicks/impressions by priority cluster
- English organic leads by country
- top landing pages and query intent
- branded versus non-branded query mix

### Conversion

- qualified brief submissions
- landing → brief start → submit rate
- service/project assisted conversion
- WhatsApp/email/phone click and eventual qualification where attributable
- median first-response time

### Content/proof

- flagship cases with approved evidence
- commercial pages with linked case and native locale parity
- articles producing service/case engagement, not raw traffic alone

Do not set percentage-growth targets until analytics duplication is fixed and a clean 2–4 week baseline exists.

## Risks

| Risk | Mitigation |
|---|---|
| Content redesign starts before DB stabilization | Make P0 exit criteria a release gate. |
| Claims cannot be substantiated | Replace with verified operating facts; do not invent results. |
| English production outruns editorial capacity | Publish fewer native pages; keep incomplete locales draft/noindex. |
| URL consolidation loses equity | Use GSC/backlink export, relevance map, one-hop 301 and monitoring. |
| Rich media hurts performance | Set format/poster/dimension/load budgets; preserve strongest visuals. |
| Too many formats remain politically difficult to retire | Keep non-indexed catalogue filters while concentrating SEO/navigation on proven capabilities. |
| International promise exceeds operations | State exact delivery/partner model and markets. |
